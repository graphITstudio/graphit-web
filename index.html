Nuestros Paquetes

Esencial

Pensado para negocios, emprendimientos o profesionales que necesitan una presencia web clara y funcional.

  • Diseño y desarrollo de sitio web
  • Estructura y navegación del sitio
  • Diseño de interfaz (UI).
  • Wireframe.
  • Adaptación a dispositivos móviles y tabletas.
  • Hasta 5 páginas o secciones principales, según el alcance definido para el proyecto.
  • Botones y enlaces de navegación.
  • Integración con redes sociales.
  • Integración con WhatsApp.
  • Formulario de contacto básico.
  • Carga de contenido proporcionado por el cliente.
  • Configuración básica del sitio para su publicación.
  • Pruebas de funcionamiento.
  • Periodo de seguimiento y garantía posterior a la publicación.
  • Manual básico
Más solicitado

Profesional

Pensado para empresas o proyectos que requieren una presencia web más completa y mayores posibilidades de interacción.

  • Todo Esencial
  • Hasta 10 páginas o secciones principales, según el alcance definido para el proyecto.
  • Blog o sección de noticias, cuando aplique.
  • Galerías de imágenes o contenido multimedia.
  • Formularios personalizados.
  • Integraciones con herramientas externas de uso común.
  • Configuración SEO básica.
  • Configuración básica de herramientas de analítica, cuando corresponda.
  • Animaciones e interacciones visuales básicas.
  • Funcionalidades adicionales de complejidad media, previamente definidas.
  • Pruebas ampliadas de funcionamiento y visualización

Personalizado

Pensado para proyectos que requieren funcionalidades, estructuras o soluciones específicas que superan el alcance de los planes anteriores

Puede incluir, de acuerdo con los requerimientos del proyecto:

  • Arquitectura y estructura web personalizada.
  • Diseño visual completamente personalizado.
  • Mayor número de páginas y secciones según lo requerido.
  • Tienda virtual.
  • Carrito de compras.
  • Integración de pasarelas de pago.
  • Sistemas de reservas.
  • Sistemas de usuarios y perfiles.
  • Buscadores y filtros avanzados.
  • Integraciones mediante API.
  • Automatizaciones.
  • Bases de datos o sistemas de gestión de información.
  • Funcionalidades desarrolladas específicamente para el proyecto.
  • Integraciones con plataformas o servicios externos.
  • Otras necesidades técnicas o funcionales previamente acordadas.
